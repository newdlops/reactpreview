# 로컬 신경망의 문제별 학습

Page Inspector의 작은 신경망은 결정적 resolver가 허용한 후보만 평가합니다. 예외, 조건, 데이터
컬렉션, 로컬 UI 상태 전환, 페이지 선택, 페이지 실행, 빈 출력, 렌더 상태, 미렌더링과 일반 문제를
독립된 출력 헤드로 학습합니다. 처음 사용하는 헤드는 중립 점수 `0.5`로 시작하며, 검증된 렌더 결과와
rollback만 학습 근거가 됩니다.

가중치는 같은 유형의 문제 사이에서 재사용하지만 후보의 연속 실패와 성공 기록은 문제 종류 및 제한된
특징 벡터 전체로 만든 문맥 해시별로 구분합니다. 동일한 복구 전략이 다른 데이터 구조에서 실패했다고
현재 문제에서도 실패한 것으로 취급하지 않습니다. 기존 버전 3·4 가중치는 유지하며, 문맥을 알 수 없는
이전 후보 기록은 새 문맥의 실패 횟수로 사용하지 않습니다. 이전에 일반 헤드로 처리하던 페이지 실행과
로컬 UI 전환은 새 전용 헤드에서 중립 상태로 시작합니다.

익명 후보 기록은 프로필 전체에서 최대 192개입니다. 현재 10개 유형마다 최신 19개까지 우선 보존하고,
남는 공간은 전체 최신 기록으로 채워 특정 문제의 반복 학습이 다른 유형의 기억을 모두 밀어내지 않게
합니다. 브라우저 저장·패널 병합·확장 호스트 병합에 같은 보존 규칙을 적용합니다. 저장되는 값은 제한된
가중치, 익명 해시와 검증 결과 카운터이며 프로젝트 소스, 실제 데이터와 특징 벡터는 저장하지 않습니다.
